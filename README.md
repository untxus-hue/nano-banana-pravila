# Официальные правила Google для Nano Banana

Чистая база правил написания промптов для моделей Nano Banana, собранная только из официальных материалов Google, с дословными цитатами и полной трассировкой.

- `правила/` — результат: ПРАВИЛА.jsonl, ТЕРМИНЫ.json, ПРОПУЩЕНО.json, ИТОГ.md (что это, цифры, как проверить).
- `источники/` — реестр официальных страниц, их текст и html, извлечённые единицы с цитатами.

История сборки (сбор, извлечение, сведение, сшивка, проверки, ТЗ агентам) — в git: тег `этапы-2026-09-25`.
