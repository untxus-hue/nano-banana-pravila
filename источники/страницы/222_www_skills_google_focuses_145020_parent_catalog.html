    Overview

    The model is a powerful, generalist multimodal model that offers state-of-the-art image generation and conversational image editing capabilities. is also able to show its work, allowing you to see the 'thought process' behind the generated output.

    In this lab, you use the model in Agent Platform using the Google Gen AI SDK. You explore an image generation scenario and an image editing scenario.

    Prerequisites

    Before starting this lab, you should be familiar with:

    • Basic Python programming.
    • General API concepts.
    • Running Python code in a Jupyter notebook on Agent Platform Workbench.

    Objectives

    You use the Google Gen AI SDK within a Jupyter notebook to do the following:

    • Generate images: Create images from text, view the model's reasoning, use search grounding, and adjust aspect ratios.
    • Edit images: Modify specific areas (localization), edit via chat (multi-turn), and multiple reference images.
    NOTE: Expect higher latency when using this model compared to Nano Banana as a result of the more advanced capabilities.

You perform specific tasks like "localization" to translate text within an image and use multi-turn chat to iteratively refine an image through conversation.
