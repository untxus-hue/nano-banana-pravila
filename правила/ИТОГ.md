# ИТОГ: официальные правила Google для Nano Banana (слой «промпт»)

Версия: 2026-09-25-финал. Собрано 24–26.09.2026 из официальных материалов Google (документация Gemini API, Vertex AI / Agent Platform, Firebase, карточки моделей DeepMind, блоги Google, справка продуктов, ноутбуки и codelabs Google).

## Что здесь
- `правила/ПРАВИЛА.jsonl` — 270 записей: правила для того, кто пишет промпт для Nano Banana (модели gemini-3-pro-image, gemini-3.1-flash-image, gemini-3.1-flash-lite-image, gemini-2.5-flash-image). По темам: промптинг 54, рефы 45, камера_свет_композиция 33, редактирование 32, стиль 32, текст_в_кадре 29, мультиход 14, форматы_разрешение 8, grounding 7, модели_сравнение 5, продукт_ui 5, thinking 3, api_код 2, безопасность_водяной_знак 1. По видам: правило_промпта 141, возможность_модели 50, формула_шаблон 28, процедура 24, ограничение_модели 21, факт_лимит 5, политика 1. По силе: возможность 138, рекомендация 95, факт 36, требование 1. Выведенных из примеров (derived): 48.
- `правила/ТЕРМИНЫ.json` — 287 терминов Google (слова для промптов и понятия) с определениями, синонимами, омонимами и ссылками на записи.
- `правила/ПРОПУЩЕНО.json` — что сознательно не вошло (1 запись: текстовый шаблон, не про картинки).
- `источники/РЕЕСТР.jsonl` — 355 официальных страниц: url, заголовок, даты, модели, доказательство официальности; у 218 страниц есть извлечение.
- `источники/страницы/` — текст и html 218 страниц, из которых извлекались единицы (остальные страницы реестра — копии тех же статей по другим адресам).
- `источники/единицы/стр_<id>.json` — все единицы (факты, правила, примеры) каждой страницы с дословными цитатами: 5 010 единиц на 218 страниц.

## Запись правила
`id` (П-<тема>-<n>), `ядро` (код ядра, из которого сделана), `title_en`, `content_en` (текст правила по-английски: класс, не случай; настоящее время; без хеджа; формулы Google дословно), `unit_kind`, `strength` (факт | возможность | рекомендация | требование), `derived`, `models` (pro, nb2, lite, nb25), `models_partial`, `applies_when_en`, `not_applies_when_en`, `needs_from_prompt_en`, `forbids_in_output_en` (что из примеров нельзя утащить в чужой промпт), `caveats_en`, `examples` (промпты Google дословно), `canaries_en` (фразы задач, на которых правило обязано сработать), `terms`, `паспорт` (источники с E-кодами, url, датами, рангом; лучший источник; статус; связи).

## Как проверить любое правило
`паспорт.источники[].код` = E-<стр>-<n> → `источники/единицы/стр_<стр>.json` → единица с этим кодом и её дословная цитата → `источники/страницы/<стр>_*.txt` (и .html) → `источники/РЕЕСТР.jsonl` (url, дата, доказательство официальности).

## Как собиралось (кратко)
1. Сбор до отказа: 359 официальных страниц, строгая проверка официальности (домен Google + второй признак), 4 неофициальные удалены. 2. Извлечение единиц с цитатами (Opus, 218 страниц), проверено скриптом: все цитаты найдены. 3. Сведение в ядра по 17 темам, противоречия по правилам (модель → дата → ранг → опечатка → гайд против примера → текст против кода → продукт против API). 4. Сшивка тем, проход поперёк (споры, таблица моделей, словарь), независимая проверка смысла всех 1 307 ядер (выдуманных 0), правки по 782 замечаниям. 5. Конвертация слоя «промпт» в форму правил, чистка дублей, финальная независимая проверка 271 записи против цитат (255 подтверждено, 16 частично, 0 не подтверждено), исправление.
Слои «инструкция агенту» (параметры API, процедуры) и «справка» (цены, лимиты, продукты, политика) в этот результат не входят, они есть в истории репозитория (тег `этапы-2026-09-25`, папка `сведение/исправлено/`).

## Решения владельца
Старая модель 2.5 — отдельная модель, её правила только для неё. Отрицания в промпте — как у Google: позитивная форма рекомендуется, короткие явные исключения («No text») допустимы. Обязательного порядка блоков Google не задаёт; «начинать с типа кадра» — выведено из примеров. Выведенные из примеров правила помечены derived и не сильнее рекомендации. Imagen снят Google 17.08.2026, его правила не включены.
