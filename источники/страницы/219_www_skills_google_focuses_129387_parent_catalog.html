    Overview

    In this lab, you'll explore the powerful multimodal capabilities of Google AI Studio, focusing on generative AI and robotics spatial understanding. Through practical exercises, you will gain hands-on experience with cutting-edge AI models and learn how to integrate them into your applications. As a Museum Curator and Exhibit Designer, you'll use these tools to brainstorm and prototype elements for a new museum exhibit.

    Explore other content in the Gemini Enterprise Agent Ready (GEAR) program.

    What you'll learn

    In this lab, you will learn how to:

    • Prompt models to generate images.
    • Prompt a model to analyze a long-format video.
    • Build a robotics spatial understanding app from a template.
    • Prompt the robotics spatial understanding app prototype to identify items in an image.

    Task 1. Generate images

    In this task, you act as the curator generating concept art for a new dinosaur exhibit. This involves using models designed specifically for media generation.

    Generate concept art with Gemini image generation

    1. In the left navigation menu, click Playground to open the main chat interface.

    2. In the right-hand panel, open the Run settings sidebar and click the default Gemini model.

    3. Navigate to the Gemini tab under Model selection, and select .

    4. In the prompt input field, enter a request for your concept art:

    A photorealistic image of a futuristic natural history museum lobby, with a giant T-Rex skeleton made of glowing blue crystals.

    1. Click Run and review the generated image. This image could serve as the cornerstone for your new exhibit's design.

    2. For the pop-up, click Enable Google Drive and then choose your student account (e.g., student-XX-YYYY@qwiklabs.net) and grant any necessary permissions to continue.

    3. Save your prompts and responses by clicking the edit icon beside the auto-generated title and then for Prompt name, type Futuristic Museum Lobby.

    4. Click Save.

    Task 2. Prompt a model to analyze a long-format video

    In this task, you'll research existing successful exhibits by asking Gemini to analyze a video tour of the American Museum of Natural History.

    1. In the left navigation menu, click Playground to return to the main chat interface.

    2. In the right-hand panel, open the Run settings sidebar and click the default Gemini model (currently set to ) to select a different model.

    3. Under Model selection, click on the Gemini tab and select the model, as this is designed to handle large inputs like videos.

    4. Click the attachment icon (a plus sign inside a circle) inside of the prompt bar and select Sample Media.

    5. From the list of videos, select the American Museum of Natural History Tour - 10 Min and click Add to prompt.

    6. Wait for the video to process. You will see the video appear in the prompt area with its token count displayed.

    Note: You'll notice a large token count appears after adding the video. A language model "sees" a video as a sequence of thousands of individual frames. Each frame is converted into numerical data called tokens for the model to analyze. The processing time you see is the model 'reading' all of these tokens before it can answer your question about the video.
    1. In the text field above the video, enter the following prompt:
    Please provide a summary of the main exhibits shown in this video tour. List each distinct hall or section and give a one-sentence description of each.

    1. Click Run and review the model's text summary of the video's content.

    2. Save your prompts and responses by clicking the edit icon beside the auto-generated title and then for Prompt name, type Museum Exhibit Highlights.

    3. Click Save.

    Note: If the template is not visible, select All apps to view the full gallery of app templates.
    1. Click the Robotics Spatial Understanding template to instantly generate the app prototype.

    1. The interface will load with the application's code and a live Preview of the app on the right.

    Task 4. Prompt the robotics spatial understanding app prototype

    In this task, you'll test the prototype you just built. You'll simulate a visitor interaction by asking the app to identify objects within a sample image from a harvest festival exhibit, and modify the code to change the bounding box color.

    Explore the app's features

    1. In the app's Preview pane, locate the sample images at the bottom. Click on the image that shows several mangos on display.

    2. Above the prompt box, ensure the 2D bounding boxes button is selected. In the PROMPT input box, type mango and click Send. Observe the standard bounding boxes drawn around the mangos.

    Note: A bounding box is a rectangle that highlights the precise location of an object in an image. It's the fundamental way a computer vision model demonstrates its robotics spatial understanding—by showing you not just what it sees, but where it sees it.
    1. Finally, select the Points button and click Send. Observe how the model places key points on the detected objects.

    Modify the app with the Code Assistant

    1. Before proceeding, ensure the 2D bounding boxes button is selected in the Preview pane again.

    2. Now, direct your attention to the Code assistant input field at the bottom left of the screen that says "Make changes, add new features...". Type the following command:

    Make the bounding boxes red.

    1. Click Remix or press the assistant’s Send button, then select Remix app. A new browser window will open, click Acknowledge on the page and watch as the assistant updates the application code in the editor window.

    2. Once the code has been updated, return your focus to the Preview pane on the right. With the mango image and 2D bounding boxes still selected, click the Send button for the mango prompt one last time.

    3. Observe the result. The bounding boxes drawn around the mangos should now be red, demonstrating that you have successfully modified a live application with a simple text command.

    4. Optional Challenge: You've seen how easy it is to modify the app with text. Before you finish, try giving the Code assistant a few more commands. Can you figure out how to:

      • Change the bounding box color to green?
      • Make the bounding box line dotted instead of solid?
      • Change the bounding box to a thick, dashed line?
      • Change the label text color to white?

    5. Save your prompts and responses by clicking the edit icon beside the auto-generated title and then for Prompt name, type Robotics Spatial Understanding.

    6. Click Save.
